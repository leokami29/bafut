Key WCAG 2.2 AA Criteria for Tactical Boards:
- 1.4.3 Contrast (Minimum): Text and images of text have a contrast ratio of at least 4.5:1 (or 3:1 for large text).
- 1.4.11 Non-text Contrast: UI components and graphical objects have at least 3:1 contrast against adjacent colors.
- 2.1.1 Keyboard: All functionality operable through keyboard (Tab, Enter, Space).
- 2.4.7 Focus Visible: Any keyboard operable user interface has a mode of operation where the keyboard focus indicator is visible.
- 2.5.5 / 2.5.8 Target Size: Minimum target size >= 24x24px (AA), 44x44px recommended for touch ergonomics.
- 4.1.2 Name, Role, Value: Controls have accessible names and correct ARIA states (e.g. aria-pressed for toggles).
- 4.1.3 Status Messages: Live regions (aria-live="polite") to inform users of dynamic changes without disrupting focus.
